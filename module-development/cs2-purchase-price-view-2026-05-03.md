# CS2 内购模块界面收敛与全区价格查看

日期：2026-05-03

## 本次目标

- 继续收敛内购商品列表密度，避免默认状态过于拥挤
- 在不改动真实 GC 内购链路的前提下，增加单商品全币种价格查看
- 明确展示 `rates` 的定位，避免误解成独立外汇接口

## 实现内容

### 1. 商品列表改为“分类折叠 + 商品二级折叠”

- 一级仍按 `工具 / 钥匙 / 音乐盒 / 胶囊 / 印花` 分类折叠
- 默认只显示：
  - 商品名称
  - 类型
  - 当前选中账号币种下的价格
  - `查看价格(n)` 按钮
  - `加入已选账户` 按钮
- 不再在默认行平铺 USD、本地币、分类等多列信息

### 2. 增加全区价格查看弹窗

- 点击 `查看价格(n)` 后弹出独立价格窗口
- 弹窗展示：
  - 分类
  - DefIndex
  - 币种数量
  - 所有可用币种价格，一行一条
- 币种价格使用现有 `/api/purchase/items` 返回的 `item.prices`
- 每行固定展示：
  - 币种
  - 原价
  - 折算人民币
  - 参考 `rate`

### 3. 价格按人民币折算后升序排序

- 折算目标统一为 `CNY`
- 折算使用独立 USD 汇率表中的 `rates`
- 排序方式为：
  - 先按折算后的人民币价格从低到高
  - 折算结果一致时按币种 ISO 排序
- 这里的人民币折算仅用于对比展示，不代表独立结算汇率

### 4. 页面摘要补充价格来源说明

- 商品摘要区新增：
  - `价格源：GC 商品目录`
  - `汇率参考：...`
- 当前 `rates` 的用途只作为前端参考展示
- `rates` 来自独立 USD 汇率表，不再使用商品目录价格反推
- 当前 `item.prices` 仍然以 GC 商品目录的真实价格为准

## 代码位置

- 前端逻辑：`public/app.js`
- 前端样式：`public/styles.css`

## 结果

- 商品列表默认态明显更紧凑
- 可直接通过弹窗查看每个商品在所有区/所有币种下的价格
- 价格列表支持按折算人民币后的结果从低到高查看
- 不影响现有真实 GC 商品目录查询和真实下单流程

## 备注

- 这次只改前端展示，不需要调整 53110 服务端流程
- 如果后续要加“价格面板内搜索币种”或“固定展示常用区价格对比”，可以继续在当前结构上扩展
